🎮 Top-Down 3D Action Prototype (Unity) — WIP

A top-down 3D action game prototype built in Unity as part of my focused gameplay programming development. This project is being developed entirely from scratch with strong emphasis on clean architecture, system separation, and scalable gameplay design.

⚠️ Currently in active development.

Smooth top-down movement using CharacterController

Physics-aware vertical handling

Decoupled animation system (animation logic separated from gameplay logic)

Parameter-driven Animator setup

🪙 Coin Collection System

Trigger-based pickup detection

Modular coin behavior

Score tracking system

Expandable collectible structure

👾 Basic Enemy AI

Player detection

Chase behavior

Simple decision-based logic

Structured for future expansion (patrol, attack states, etc.)

Interactive traps implemented using a state machine pattern

Level progression system

Main Menu
